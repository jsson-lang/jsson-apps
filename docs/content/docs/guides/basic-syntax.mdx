## Core Concepts

JSSON has just a few simple rules. Master these, and you'll be writing clean configs in no time.

### Assignments

The foundation of JSSON: key-value pairs.

```javascript
name := João
age := 25
active := true
```

**Rules:**

- No quotes needed around keys
- Use `=` for assignment and `:=` for variable declarations
- One assignment per line (no commas!)

### When to Use Quotes

This is the #1 question! Here's the simple rule:

<Tabs items={['No Quotes Needed', 'Quotes Required']}>
  <Tab value="No Quotes Needed">
```javascript
// Single words
name := João
city := Tokyo
status := active

// Numbers
age := 25
price := 19.99

// Booleans
admin := true
disabled := false
```
  </Tab>
  <Tab value="Quotes Required">
```javascript
// Values with spaces
title := "Software Engineer"
message := "Hello, World!"

// Values with special characters
email := "user@example.com"
url := "https://example.com"

// Empty strings
empty := ""
```
  </Tab>
</Tabs>

<Callout type="info">
**Pro Tip:** When in doubt, use quotes! They always work. But skipping them makes your JSSON cleaner.
</Callout>

## Data Types

JSSON supports all JSON data types with a friendlier syntax.

### Strings

<Tabs items={['JSSON', 'JSON Output']}>
  <Tab value="JSSON">
```javascript
// Without quotes (simple identifiers)
firstName = João
lastName = Silva

// With quotes (spaces or special chars)
fullName = "João Silva"
email = "joao@example.com"
bio = "Developer from Brazil 🇧🇷"
```
  </Tab>
  <Tab value="JSON Output">
```json
{
  "firstName": "João",
  "lastName": "Silva",
  "fullName": "João Silva",
  "email": "joao@example.com",
  "bio": "Developer from Brazil 🇧🇷"
}
```
  </Tab>
</Tabs>

### Numbers

## Objects

Objects in JSSON are beautifully simple — no colons, no commas, just clean nesting.

### Simple Objects

<Tabs items={['JSSON', 'JSON Output']}>
  <Tab value="JSSON">
```javascript
user {
  name = João
  age = 25
  email = "joao@example.com"
}
```
  </Tab>
  <Tab value="JSON Output">
```json
{
  "user": {
    "name": "João",
    "age": 25,
    "email": "joao@example.com"
  }
}
```
  </Tab>
</Tabs>

### Nested Objects

<Tabs items={['JSSON', 'JSON Output']}>
  <Tab value="JSSON">
```javascript
user {
  name = João
  contact {
    email = "joao@example.com"
    phone = "+55 11 99999-9999"
  }
  preferences {
    theme = dark
    language = pt-BR
    notifications {
      email = true
      push = false
    }
  }
}
```
  </Tab>
  <Tab value="JSON Output">
```json
{
  "user": {
    "name": "João",
    "contact": {
      "email": "joao@example.com",
      "phone": "+55 11 99999-9999"
    },
    "preferences": {
      "theme": "dark",
      "language": "pt-BR",
      "notifications": {
        "email": true,
        "push": false
      }
    }
  }
}
```
  </Tab>
</Tabs>

<Callout type="info">
**Use Case:** Objects are perfect for configuration files, API responses, and any hierarchical data.
</Callout>

## Arrays

Arrays in JSSON are just like JSON, but cleaner — no quotes needed for simple values!

### Simple Arrays

<Tabs items={['JSSON', 'JSON Output']}>
  <Tab value="JSSON">
```javascript
// Numbers
numbers = [ 1, 2, 3, 4, 5 ]

// Strings (no quotes needed!)
colors = [ red, blue, green, yellow ]

// Mixed types
mixed = [ João, 25, true, 1.75 ]

// With quotes when needed
cities = [ "São Paulo", "Rio de Janeiro", Tokyo ]
```
  </Tab>
  <Tab value="JSON Output">
```json
{
  "numbers": [1, 2, 3, 4, 5],
  "colors": ["red", "blue", "green", "yellow"],
  "mixed": ["João", 25, true, 1.75],
  "cities": ["São Paulo", "Rio de Janeiro", "Tokyo"]
}
```
  </Tab>
</Tabs>

### Arrays of Objects

<Tabs items={['JSSON', 'JSON Output']}>
  <Tab value="JSSON">
```javascript
users = [
  { name = João, age = 25 },
  { name = Maria, age = 30 },
  { name = Pedro, age = 28 }
]
```
  </Tab>
  <Tab value="JSON Output">
```json
{
  "users": [
    { "name": "João", "age": 25 },
    { "name": "Maria", "age": 30 },
    { "name": "Pedro", "age": 28 }
  ]
}
```

  </Tab>

```javascript
  allowedMethods = [ GET, POST, PUT, DELETE ]
```

  <Tab value="JSON Output">

```json
    "host": "localhost",
```

## Comments

Document your configs with comments — they're ignored during transpilation.

```javascript
// This is a single-line comment

// Application settings
app {
  name = "My App"  // Inline comments work too!
  version = "1.0.0"

  // Server configuration
  server {
    port = 8080  // Default port
    host = localhost
  }
}
```

<Callout type="info">
**Pro Tip:** Use comments to explain _why_ a setting exists, not just _what_ it is.
</Callout>

## Variables

Declare variables with `:=` to store values for reuse. Variables are **not** included in the final JSON output.

<Tabs items={['JSSON', 'JSON Output']}>
  <Tab value="JSSON">
```javascript
// Declare variables
api_key := "sk-1234567890"
base_url := "https://api.example.com"
timeout := 5000

// Use them in configuration
production {
  apiKey = api_key
  endpoint = base_url + "/v1"
  timeout = timeout
}

development {
  apiKey = api_key
  endpoint = base_url + "/dev"
  timeout = timeout
}
```
  </Tab>
  <Tab value="JSON Output">
```json
{
  "production": {
    "apiKey": "sk-1234567890",
    "endpoint": "https://api.example.com/v1",
    "timeout": 5000
  },
  "development": {
    "apiKey": "sk-1234567890",
    "endpoint": "https://api.example.com/dev",
    "timeout": 5000
  }
}
```
  </Tab>
</Tabs>

### Local Variables

Variables declared inside objects are **local** to that scope:

```javascript
global := 100

obj {
  local := 50
  value = local   // Uses local (50)
  outer = global  // Uses global (100)
}

// 'local' is not accessible here
```

<Callout type="info">
**Use Case:** Variables are perfect for configuration constants, API keys, and any value you use multiple times.
</Callout>

## Building from Simple to Complex

Let's build a real-world example step by step.

### Step 1: Basic Info

```javascript
name = "My Application"
version = "1.0.0"
debug = true
```

### Step 2: Add Objects

```javascript
name = "My Application"
version = "1.0.0"
debug = true

server {
  host = localhost
  port = 8080
}
```

### Step 3: Add Arrays

```javascript
name = "My Application"
version = "1.0.0"
debug = true

server {
  host = localhost
  port = 8080
  allowedOrigins = [ "http://localhost:3000", "https://example.com" ]
}
```

### Step 4: Add Nesting

```javascript
name = "My Application"
version = "1.0.0"
debug = true

server {
  host = localhost
  port = 8080
  allowedOrigins = [ "http://localhost:3000", "https://example.com" ]
}

database {
  connection {
    host = localhost
    port = 5432
    name = myapp_db
  }
  pool {
    min = 2
    max = 10
  }
}
```

See how natural it feels? No JSON ceremony, just clean configuration!
