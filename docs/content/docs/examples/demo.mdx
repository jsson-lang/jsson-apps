This example demonstrates the fundamental features of JSSON in a single, practical configuration file.

## The JSSON

```javascript
// User configuration
user {
  name = João
  age = 20
  admin = true
  roles = [ "admin", "editor" ]
  
  config {
    theme = dark
    language = pt-BR
    notifications = true
  }
  
  preferences {
    fontSize = 14
    lineHeight = 1.5
    autoSave = true
  }
}
```

## The JSON Output

```json
{
  "user": {
    "name": "João",
    "age": 20,
    "admin": true,
    "roles": ["admin", "editor"],
    "config": {
      "theme": "dark",
      "language": "pt-BR",
      "notifications": true
    },
    "preferences": {
      "fontSize": 14,
      "lineHeight": 1.5,
      "autoSave": true
    }
  }
}
```

## What This Demonstrates

### ✅ Simple Assignments

```js
name = João
age = 20
```

No quotes needed for simple values!

### ✅ Booleans

```js
admin = true
notifications = true
autoSave = true
```

Native boolean support.

### ✅ Arrays

```js
roles = [ "admin", "editor" ]
```

Mix quoted and unquoted values as needed.

### ✅ Nested Objects

```js
user {
  config {
    theme = dark
  }
}
```

Clean, readable nesting without JSON ceremony.

### ✅ Comments

```js
// User configuration
```

Document your configs!

### ✅ Mixed Data Types

```js
fontSize = 14        // Number
lineHeight = 1.5     // Float
autoSave = true      // Boolean
theme = dark         // String
```

All JSON types supported.

## Try It Yourself!

1. Save the JSSON code above to `demo.jsson`
2. Run: `jsson -i demo.jsson -o demo.json`
3. Open `demo.json` to see the result!

## Variations to Try

### Add More Nesting

```javascript
user {
  profile {
    personal {
      name = João
      age = 20
    }
    professional {
      title = "Developer"
      company = "Tech Corp"
    }
  }
}
```

### Add Arrays of Objects

```javascript
user {
  name = João
  socialMedia = [
    { platform = twitter, handle = "@joao" },
    { platform = github, handle = "joaodev" }
  ]
}
```

### Add More Arrays

```javascript
user {
  name = João
  skills = [ JavaScript, Python, Go ]
  hobbies = [ coding, reading, gaming ]
  languages = [ Portuguese, English, Spanish ]
}
```
