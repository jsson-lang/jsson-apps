0.9. What's New in v0.0.5? 🎉

JSSON v0.0.5 introduced powerful new capabilities:• Nested Maps 🔄 — Map transformations inside other maps for multi-level pipelines• Nested Arrays 📦 — Full support for arrays within arrays at any depth• Universal Ranges 🔢 — Use ranges anywhere expressions are allowed• Stable Arithmetic ➗ — Division and modulo work everywhere with clear error messages

These features turn JSSON into a true data-generation powerhouse! 🚀
